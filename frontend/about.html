About Online Bookstore

Online Bookstore is a cloud-based web application that allows users to browse books, view book details, add books to a cart, and place orders.

The application is designed using a microservice architecture. Book information is managed by the Catalog Service, while shopping and order operations are managed by the Order Service.

The frontend communicates with the backend services using REST APIs. Book cover images will be stored in cloud-based storage.
